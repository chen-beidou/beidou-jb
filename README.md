# beidou-jb

一个面向中文短剧、AI 漫剧和影视剧本的创作 Skill。

它主要完成两类任务：

1. 检查、修改、重写和升级已有剧本。
2. 把小说、网文、故事梗概或章节改编成可拍、可演、可生成的视频剧本。

核心目标不是堆砌“金句”或套用模板，而是先保证人物动机、信息权限和事件因果成立，再处理情绪、节奏、高潮、钩子、对白声线与自然中文表达。

## 能做什么

### 剧本检查与升级

- 检查逻辑漏洞、人物降智和信息凭空出现
- 修复场次功能、冲突升级和情绪过渡
- 强化开场钩子、中段转折、高潮选择和集末钩子
- 区分人物声线，减少解释性对白
- 去除常见 AI 写作痕迹
- 检查 AI 漫剧的角色、场景、动作和资产复杂度
- 根据内部质量门进行评分、修复和终检

### 小说改编剧本

- 提取原作不可变内核和关键设定
- 建立人物关系、欲望、秘密与状态表
- 压缩弱支线、重复冲突和不可视化心理描写
- 生成改编总纲、分集节拍和完整剧本
- 保留关键情感承诺，同时提高短剧节奏
- 区分原作事实、合理推断和改编新增内容

## 适用场景

- 中文短剧、竖屏短剧
- AI 漫剧、动态漫、AIGC 视频剧本
- 网文和小说影视化改编
- 分集大纲、样板集、完整剧本
- 剧本医生、终稿质检、投稿前升级

## 安装

### 方法一：下载压缩包

1. 在仓库右上角选择“Code”。
2. 选择“Download ZIP”。
3. 解压后确认文件夹名称为 `beidou-jb`。
4. 将整个文件夹放入 Codex 的 Skills 目录：
   - Windows：`%USERPROFILE%\.codex\skills\beidou-jb`
   - macOS / Linux：`~/.codex/skills/beidou-jb`
5. 重新打开 Codex 或新建任务。

### 方法二：使用 Git

```bash
git clone https://github.com/chen-beidou/beidou-jb.git ~/.codex/skills/beidou-jb
```

Windows PowerShell：

```powershell
git clone https://github.com/chen-beidou/beidou-jb.git "$env:USERPROFILE\.codex\skills\beidou-jb"
```

## 怎么使用

安装后，在请求中直接点名 `$beidou-jb`。

### 检查剧本

```text
使用 $beidou-jb 检查这份剧本。先列出致命问题和证据，不要直接重写全文。
```

### 修改并升级剧本

```text
使用 $beidou-jb 修改并升级这份 AI 漫剧剧本。重点修复人物动机、节奏、情绪点、高潮和集末钩子，最后直接给完整终稿。
```

### 小说改编剧本

```text
使用 $beidou-jb 把这篇小说改成竖屏 AI 漫剧。先做改编总纲和分集节拍，再写前 3 集完整剧本。
```

### 联合模式

```text
使用 $beidou-jb 先把小说章节改成剧本，再按剧本医生流程终检和升级。保留人物关系、世界规则和关键事件。
```

## 建议提供的信息

资料越完整，成稿越稳定：

- 原小说、剧本或故事梗概
- 题材与目标受众
- 发布平台或制作方式
- 横屏或竖屏
- 单集时长与总集数
- 必须保留和禁止修改的内容
- 期望风格、尺度和参考作品

信息不足时，Skill 会采用保守默认值继续工作：竖屏 AI 漫剧、单集 60–90 秒、每集 1–3 个场景、2–4 个主要出场人物。

## 输出内容

根据任务不同，可能输出：

- 剧本诊断报告
- 致命问题与修改优先级
- 人物和故事状态表
- 改编总纲
- 分集节拍
- 完整剧本
- 质量门评分与未通过项
- 修复后的终稿

剧本正文不会混入聊天式前言、营销结语、评分表、emoji 或无关说明。

## 内部质量门

“S 级”表示通过本 Skill 的内部质量标准：总分至少 92/100，并且不存在逻辑断裂、动机失真、高潮无选择、人物同声、不可视化、关键设定漂移或明显 AI 套路等致命问题。

该标准用于稳定创作流程，不代表任何第三方平台一定给出 S 级评价，也不承诺商业成功。

## 自动检查脚本

较长剧本可以运行：

```powershell
python scripts/audit_script.py <剧本文件>
```

脚本会检查格式、套话、超长对白、场次标记和弱钩子等机械信号。它不能替代编剧判断，最终仍需按人物、因果和情绪进行人工冷读。
