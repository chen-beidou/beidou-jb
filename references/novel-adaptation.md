# 小说到剧本改编

## 改编原则

忠于原作的体验与人物关系，不等于逐句搬运。保留能让读者认出这部作品的欲望、冲突、关系、世界规则和标志性场面；允许压缩、合并、调序和重新设计进入方式。

## 第一步：原作提取

建立四层材料表：

- **不可变内核**：核心关系、主人公根本欲望、主要矛盾、关键世界规则、主题承诺。
- **标志性资产**：名场面、关键台词、独特道具、身份谜团、读者期待的爽点/虐点。
- **可重组材料**：支线人物、时间顺序、场景地点、背景交代方式。
- **可删除材料**：重复冲突、功能重叠人物、无后果事件、只在文字中成立的修辞段落。

不确定时注明证据所在章节。长篇输入先建立人物、时间线、规则和关键事件索引，再写剧本。

## 第二步：选取改编主轴

决定观众追看的核心问题，只保留能强化它的支线。把小说中的多个弱事件合并为更少但后果更强的戏剧事件。合并人物时同时迁移其信息功能、关系功能和后续兑现，不能只删名字。

## 第三步：把叙述转换为戏

使用以下转换：

- 心理描写 → 犹豫、错误选择、隐藏动作、身体反应、对物件的异常处理。
- 背景说明 → 当前冲突中必须使用的信息、环境证据、带立场的短台词。
- 作者评价 → 让事件后果和他人反应呈现。
- 长段回忆 → 有触发物和新信息价值的短闪回；没有新价值则删除。
- 关系介绍 → 一次权力不平等的互动。
- 能力介绍 → 先制造需要能力解决的问题，并让使用能力付出代价。

旁白只保留不可替代的主观声音、时间压缩或类型承诺。旁白不能重复画面，也不能替人物完成选择。

## 第四步：短剧化压缩

每集只保留一个主冲突。采用：开场局面 → 明确目标 → 阻力加码 → 策略变化 → 局面翻转 → 情绪余波/集末钩子。

不要平均分配原文章节。按戏剧事件和悬念单元切集。原文慢热时，可以提前展示后果或危险，但不得泄露会摧毁主谜团的答案。

## 第五步：改编审计

交付前逐项核对：

- 关键关系是否改变性质。
- 人物选择是否仍符合原作价值观和伤口。
- 新增冲突是否破坏后续逻辑。
- 合并人物是否造成信息来源消失。
- 提前事件是否让人物知道了不该知道的事。
- 名场面是否保留其情绪原因，而非只复制表面动作。
- 新增内容是否明确为改编创造，而非声称来自原著。
